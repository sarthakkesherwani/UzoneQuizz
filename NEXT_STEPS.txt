Run locally
-----------
Requirements: Node.js 18+ and MongoDB.

1. Open a terminal in the project folder.
2. Set the environment variables:

   export MONGODB_URI="mongodb://127.0.0.1:27017/uzonequiz"
   export JWT_SECRET="replace-with-a-long-random-secret"

3. Start the app:

   npm start

4. Open:

   http://localhost:5050

Deployment
----------
1. Upload the project files to your repository/hosting service.
2. Configure MONGODB_URI and JWT_SECRET in the hosting environment.
3. Deploy using the existing Node start command:

   npm start

4. After deployment, log in as the teacher and open My quizzes.
5. Confirm the three LeetCode quizzes are Published.
6. Open one quiz as a student, submit it, and expand “View reference solution”.

Notes
-----
- The LeetCode questions are paraphrased educational summaries, not copied full problem statements.
- Solutions use Python 3 and standard LeetCode-style method signatures.
- Reference solutions are shown after submission so they do not reveal answers during the quiz.
